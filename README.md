SwiftCodeHub

Welcome to SwiftCodeHub! 🚀 This repository contains a powerful backend application built using Spring Boot, Hibernate, and Docker.

📌 Getting Started

Follow the steps below to set up and run the project on your local machine.

1️⃣ Install Dependencies

Ensure you have the following installed:

Docker

Git

2️⃣ Clone the Repository

git clone https://github.com/aloix123/SwiftCodeHub.git
cd SwiftCodeHub

3️⃣ Set Up PostgreSQL Database

Start the database container with Docker:

docker-compose up db --build

4️⃣ Run Tests

Execute the test suite to ensure everything is working:

docker-compose up swiftcode-test --build

5️⃣ Run the Backend Application

Start the application using Docker:

docker-compose up swiftcode-app --build

6️⃣ Access the API

Open your browser and go to: http://localhost:8080/
